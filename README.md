# 📖 Overview

SmartSpace is a modern full-stack AI-powered web application that allows users to design and visualize beautiful interiors effortlessly. Whether planning a bedroom makeover, designing a living room, or creating a productive office space, SmartSpace provides intelligent recommendations tailored to the user's preferences.

Built using the latest web technologies, the platform offers an elegant user interface, responsive layouts, secure authentication, cloud database integration, and AI-assisted room generation for an exceptional design experience.

# ⚙ Installation

## Clone Repository

```bash
git clone https://github.com/Jadav-Ruthwik/SmartSpace-AI-Powered-Interior-Design-Platform-.git
```

Move into project directory

```bash
cd SmartSpace-AI-Powered-Interior-Design-Platform-
```

Install dependencies

```bash
npm install
```

Start development server

```bash
npm run dev
```

Open

```
http://localhost:3000
```
